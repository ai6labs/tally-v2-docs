---
title: "Updates"
description: "How Tally for Mac gets new versions."
---

Tally checks GitHub Releases for a new version when it starts. Before it installs one, it checks the download against the release's `SHA256SUMS` file.

- **Automatic updates** are on by default, so a new version downloads and installs in the background. To turn them off, open **Settings**, then **Advanced**, then **Menu bar & widgets**.
- To check now, choose **Check for Updates…** in the menu bar menu, or **Check for updates** in the same Settings section.
- **Include beta versions** in the menu bar menu is off by default. Turn it on only if you want to try pre-release versions.

<Note>
The Tally repository is private for now, so the update check cannot see new releases. Until that changes, install new versions with the [install script or by hand](/install).
</Note>

The Windows and Linux apps are paused, so there are no Windows or Linux updates.

## Your data during an update

Updates do not delete your data. Tally keeps it in the `.tally` folder in your home folder. See [Privacy](/privacy).
