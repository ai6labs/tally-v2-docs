---
title: "Install Tally"
description: "Download Tally for your Mac, verify its checksum, and install the app."
---

Tally runs on macOS. The Windows and Linux apps are paused, so there is no Windows or Linux download.

Each release has two files: `Tally-<version>.dmg` (the app) and `SHA256SUMS` (checksums to check the download). Get them from the [latest release](https://github.com/ronkaldes/tally-releases/releases/latest). The page is public, so you do not need a GitHub account. The file name carries the version, so open the release and pick the `.dmg` listed there.

## Install by hand

1. Download `Tally-<version>.dmg` and `SHA256SUMS` into the same folder.
2. Check the download before you open it:

   ```bash
   cd ~/Downloads
   shasum -a 256 -c SHA256SUMS --ignore-missing
   ```

   The line for `Tally-<version>.dmg` must end in `OK`. If it does not, delete the file and download it again.
3. Open `Tally-<version>.dmg` and drag Tally to Applications.
4. Trust the app once. Tally is not notarised by Apple, so macOS blocks the first launch. Right-click (or Control-click) Tally in Applications, choose **Open**, then **Open** again. If macOS still refuses, run this once:

   ```bash
   xattr -dr com.apple.quarantine /Applications/Tally.app
   ```

Tally adds an icon to the menu bar. The menu bar shows the same month total as Home.

## Run setup again

To run setup again and keep your data, open **Settings**, then **Local data**, then **Run setup again**.
